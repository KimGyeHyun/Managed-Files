v1.5 - 2024.09.11

1. 프로세스 분리
  - Single Filtering과 Batch Filtering을 SetMaxThread 함수로 CPU를 조절하며 동시에 사용 불가 판정
  - 8095 포트가 메인이 된 후
    Single Filtering 요청 시 8095 포트에서 처리하여 응답하도록 함
    Batch Filtering 요청 시 8096 포트로 프로세스를 1개 더 생성한 후 해당 프로세스로 재 요청
    즉시 응답은 8095포트에서 처리하며,
    배치 완료 응답은 8096 포트에서 정해진 서버로 응답을 전송하도록 함
    8096 포트는 배치 완료 응답 후 종료됨

※ 주의사항
  1. AMLFiltor.ini 파일 내 [SERVER] Server.Filtor.BatchPort=8096 항목 추가 필요
     (첨부된 AMLFiltor.ini 파일 참조)
  2. 정상적인 상황에서는 8095 포트가 8096 포트를 생성한다.
     Batch 가 완료되지 않은 시점에서 Batch를 재 요청 시 8096 포트 프로세스를 종료한 후 재기동한다.
     8095 포트를 강제로 종료한 경우, 8096 포트가 살아 있을 수 있으므로
     [작업관리자] -> [세부정보] 탭 에서 AMLFilteringService.exe 를 모두 종료할 수 있도록 한다.
